What is Agent Deck?

Agent Deck is a terminal session manager for AI coding agents. It runs each agent session in tmux and shows them all in one dashboard with live status (running, waiting, idle, error), so you can switch between them with one keystroke. It also handles forking, git worktrees, MCP servers, sessions on remote machines and long-running conductor sessions. It is one Go binary, agent-deck, with a TUI, a CLI and a web UI.

Which AI coding agents does it support?

Claude Code and Gemini CLI have full integration (status, MCP, resume, and fork for Claude). Codex, OpenCode, Copilot, Cursor (terminal), Crush, pi, Oh My Pi, Hermes Agent, Muse Code and DeepSeek Harness have built-in support with status detection and launch. Any other terminal tool works as a custom tool via [tools.*] in config.toml, or as a plain shell session.

Which operating systems does it run on?

macOS and Linux natively, and Windows through WSL (Windows Subsystem for Linux). There is no native Windows build; install WSL first, then run the installer inside it. WSL2 is recommended for full feature support, including MCP socket pooling.

How do I install it?

Run curl -fsSL https://raw.githubusercontent.com/asheshgoplani/agent-deck/main/install.sh | bash, then start it with agent-deck. Alternatives: Homebrew with brew install asheshgoplani/tap/agent-deck, Go with go install github.com/asheshgoplani/agent-deck/cmd/agent-deck@latest, or build from source with make install in a clone of the repository.

Do I need tmux?

Yes. Agent Deck runs every session inside tmux, so tmux is required. The install script checks for it and offers to install it if it is missing. It can also add an optional tmux config for mouse scrolling and clipboard copy; skip that with --skip-tmux-config.

Will it interfere with my existing tmux setup?

No. Agent Deck creates its own tmux sessions with the prefix agentdeck_*, and your existing sessions are untouched. The installer backs up your ~/.tmux.conf before adding its optional config block.

How do I update Agent Deck?

Agent Deck checks for updates automatically, and by default the TUI installs an available update on its own. For a standalone install you can also run agent-deck update; for a Homebrew install run brew upgrade asheshgoplani/tap/agent-deck. On machines where the TUI is not open every day, agent-deck update --install-timer adds a daily update run.

Homebrew installed an older version than the latest release. Why?

The Homebrew tap is updated by the release pipeline and has at times lagged behind GitHub Releases. Run brew update and then brew upgrade asheshgoplani/tap/agent-deck, and compare agent-deck --version with the latest release on GitHub. If the tap is still behind, report it on the issue tracker.

How do I uninstall it?

Run agent-deck uninstall for an interactive uninstall, or agent-deck uninstall --keep-data to remove only the binary and keep your sessions. --dry-run previews what would be removed. It removes the binary (or the Homebrew package), the agent-deck block in ~/.tmux.conf, and the agent-deck config, data and cache folders.

Is Agent Deck free? What is the license?

Yes. Agent Deck is free and open source under the MIT license. The agents themselves are billed by their own vendors: Agent Deck runs the unmodified claude CLI with your own login, and never reuses your login token to call Anthropic itself.

Does Agent Deck send any data anywhere?

Usage telemetry is opt-in and off by default: nothing is sent unless you say yes to a one-time question in the TUI, and it never includes prompts, output, titles, paths or names. agent-deck telemetry preview shows exactly what would be sent, and agent-deck telemetry off or DO_NOT_TRACK=1 turns it off. Feedback and bug reports are sent only after you confirm the full text. Agent Deck also checks GitHub for new releases.

How does status detection work?

Agent Deck polls each session and reads tool hooks where they exist, then shows running (green), waiting for your input (yellow), idle (gray) or error (red). Codex and pi report status through hooks you install once with agent-deck codex-hooks install and agent-deck pi-hooks install. Waiting sessions also appear in your tmux status bar.

What does forking a session do?

A fork is a new session that inherits the parent's conversation through the tool's own fork, supported for Claude Code, Codex, OpenCode, pi and Oh My Pi. Press f for a quick fork or Shift+F for the fork dialog. By default a quick fork gets its own git worktree and branch, carries the parent's uncommitted changes and matches its Docker sandbox.

How do I manage MCP servers?

Define your MCP servers once in ~/.config/agent-deck/config.toml, then press m on a session to toggle them per project (LOCAL) or for all projects (GLOBAL); the session restarts with the new set. With pool_all = true, the MCP socket pool shares each server across all sessions so it runs once instead of once per session.

Can several agents work on the same repository?

Yes, with git worktrees. agent-deck add . -c claude --worktree feature/a --new-branch creates a session in its own worktree and branch, so agents never overwrite each other's files. agent-deck worktree finish merges the branch, removes the worktree and deletes the session.

How do I search my past conversations?

Turn on Recall with [recall] enabled = true in config.toml. It indexes the transcripts of Claude, Codex, Gemini, pi, OpenCode and Hermes on this machine; press G in the TUI or use agent-deck recall search. To search the session list itself, press /.

Can I manage sessions on other machines?

Yes. agent-deck remote add dev user@dev-box registers a machine over SSH, and its sessions appear in your list with live status. You can create, attach, send to, fork and stop them from your own terminal. agent-deck is installed on the remote if it is missing, and agent-deck remote update --all keeps remotes current.

What is a conductor?

A conductor is a long-running agent session that supervises your other sessions. It watches for sessions that need help, answers routine questions and escalates the rest to you. Create one with agent-deck conductor setup <name>. You can talk to it from your phone through optional Telegram, Slack, Discord or Mattermost bridges, and run it on Claude Code or Codex.

Is there a web UI?

Yes. agent-deck web starts a browser UI on http://127.0.0.1:8420 with session terminals, a fleet board, costs and settings. --read-only shows output only. To listen on a non-loopback address you must protect it with --token or --token-file; without one, Agent Deck refuses to start it.

Is there a Mac app?

A native macOS app is in preview. It is built on the same agent-deck core, so it shows the sessions you already have, and its Browser panel lets agents open the reports and pages they make. There is no public download yet.

Can I use different Claude accounts?

Yes. Add named accounts under [profiles.<name>.claude] with their own config_dir, then create a session with --account <name> or pick it in the New Session dialog. agent-deck session switch-account <session> <account> moves an existing session to another account, conversation included.

Can I run agents in a sandbox?

Yes. Tick "Run in Docker sandbox" when creating a session, or set default_enabled = true under [docker]. The project folder is mounted into the container and the rest of your system stays protected. Press E on a sandboxed session to open a shell in its container.

Why can't I drag to select text in the TUI?

The TUI uses mouse reporting so clicks and scrolling work, so your terminal does not see a drag as a selection. Hold Shift while dragging (Option in iTerm2), or use the copy keys: c copies the last AI response and V copies the visible terminal text.

Where do I get help or report a bug?

Run agent-deck feedback bug to file a GitHub issue from your terminal; it shows you the full, scrubbed text before anything is sent. You can also ask on Discord or in GitHub Discussions, and ? in the TUI shows every shortcut.
