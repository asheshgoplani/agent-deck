Agent Deck

One terminal for all your AI coding agents.

Claude Code • Codex • Gemini CLI • OpenCode • and more

v1.16.35 • MIT • macOS · Linux · Windows (WSL)

Install

curl -fsSL https://raw.githubusercontent.com/asheshgoplani/agent-deck/main/install.sh | bash
brew install asheshgoplani/tap/agent-deck

Then run agent-deck. Needs tmux. Windows: inside WSL. More ways: Go, updating, uninstall → · FAQ

Why Agent Deck

See every agent's status at once

Running, waiting, idle or error, live, for every session in one list.

Switch in one key

Jump between sessions, fork a conversation, search. Keyboard-first.

Works with Claude Code, Codex, Gemini and OpenCode

And other terminal agents, side by side in the same deck.

Local and remote

Sessions on this machine and over SSH on others, plus a web UI.
