Agent Deck

Your AI agent command center

Claude Code • Codex • Gemini CLI • OpenCode • and more

v1.16.34 • MIT • macOS · Linux · Windows (WSL)

The Problem

Running Claude Code on ten projects? OpenCode on five more? Another agent somewhere in the background?

Managing many AI sessions gets messy fast. Too many terminal tabs. Hard to track what's running, what's waiting, what's done. Switching between projects means hunting through windows.

The Solution

Agent Deck is mission control for your AI coding agents.
One terminal shows every session, running, waiting or done, and one keystroke switches between them.

Install

macOS • Linux • Windows (WSL)

One command
curl -fsSL https://raw.githubusercontent.com/asheshgoplani/agent-deck/main/install.sh | bash

The script checks for tmux (required) and offers to install it. Then run: agent-deck

Homebrew
brew install asheshgoplani/tap/agent-deck
Go
go install github.com/asheshgoplani/agent-deck/cmd/agent-deck@latest

Windows: Install WSL first, then run the script inside WSL • Updating • Uninstall 

agent-deck                        # Launch the TUI
agent-deck add . -c claude        # Add this folder with Claude Code
agent-deck session fork my-proj   # Fork a supported session
agent-deck mcp attach my-proj exa # Attach an MCP server
agent-deck web                    # Web UI on http://127.0.0.1:8420

Recommended tmux Config

Mouse scroll, drag-to-copy, clipboard integration

🍎 macOS click to expand 
# Terminal
set -g default-terminal "tmux-256color"
set -ag terminal-overrides ",*256col*:Tc"

# Performance
set -sg escape-time 0
set -g history-limit 10000

# Mouse (scroll + drag-to-copy)
set -g mouse on

# Clipboard
set -s set-clipboard external
bind-key -T copy-mode-vi MouseDragEnd1Pane send-keys -X copy-pipe-and-cancel "pbcopy"
bind-key -T copy-mode MouseDragEnd1Pane send-keys -X copy-pipe-and-cancel "pbcopy"

Forking

🍴 Explore Multiple Solutions in Parallel

Try different approaches without losing context. Press f to fork a session through the tool's own fork: Claude Code, Codex, OpenCode, pi and Oh My Pi. Each fork inherits the full conversation history.

Comprehensive by default: a quick fork gets its own git worktree and branch, carries the parent's uncommitted changes, and matches its Docker sandbox. Shift+F opens the dialog to tweak it.

MCP Manager

🔌 Add Superpowers On-Demand

Attach MCP servers without touching config files. Need web search? Browser automation? GitHub integration? Toggle them on per project or globally. Agent Deck handles the restart automatically.

Running many sessions? The MCP socket pool shares each MCP server across all sessions over Unix sockets, so it runs once instead of once per session. Turn it on with pool_all = true.

🔌

Easy Toggle

Press m to open, Space to toggle

📁

Two Scopes

LOCAL (project) or GLOBAL (all), Tab to switch

🔄

Auto Restart

The session restarts with the new MCPs

Adding Available MCPs

Define MCPs once in ~/.config/agent-deck/config.toml, then toggle per project:

# GitHub integration
[mcps.github]
command = "npx"
args = ["-y", "@modelcontextprotocol/server-github"]
env = { GITHUB_PERSONAL_ACCESS_TOKEN = "ghp_your_token" }
description = "GitHub repos, issues, PRs"

# Browser automation
[mcps.playwright]
command = "npx"
args = ["-y", "@playwright/mcp@latest"]
description = "Browser automation & testing"

See the configuration reference for more.

What You Get

Git Worktrees

Many agents on one repo without conflicts. --worktree gives each session its own branch and folder; worktree finish merges and cleans up.

🔍

Recall Search

Press G to search every conversation on this machine across Claude, Codex, Gemini, pi, OpenCode and Hermes. Opt in with [recall] enabled = true.

Remotes

🖥️ Manage Sessions on Other Machines

Your other boxes show up in the same list. Register a machine over SSH and its sessions appear beside your local ones with live status. Create, attach, send, fork and stop them from your own terminal. agent-deck is installed on the remote if it's missing, and kept up to date. 

agent-deck remote add dev user@dev-box
agent-deck remote sessions dev
agent-deck remote attach dev my-session
agent-deck remote update --all

🧪 Plug in any machine

Sandbox providers make a fresh machine per session (a Docker container, a VM, anything with SSH), use it as a remote, and throw it away: agent-deck launch --provider docker.

Conductors

🎼 A Foreman for Your Fleet

A conductor is a long-running agent session that supervises all your others. It watches for sessions that need help, answers routine questions, and escalates the interesting ones to you, so a waiting worker never sits forgotten.

Talk to it from your phone through optional Telegram, Slack, Discord or Mattermost bridges. Watchers let GitHub events, webhooks and ntfy pushes wake it up. 

# Set up a conductor (asks about Telegram/Slack)
agent-deck conductor setup work --description "Work fleet"
agent-deck session start conductor-work

# Then message your bot:
/status
