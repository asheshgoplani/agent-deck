# Introduction

# Introduction

Welcome to Cartrack's developer documentation. This site gives you the exact information needed to connect to our fleet platform and to build secure vehicle-access experiences.

We currently provide two integration options:

  * **REST API** — for programmatic fleet operations such as tracking, commands, and data retrieval.
  * **Mobile SDKs (Android and iOS)** — for secure, Bluetooth-based vehicle access and telemetry in your mobile apps.

What you can expect:

  * Clear prerequisites, authentication flows, and environment details up front.
  * Versioned REST APIs with changelog visibility so you know when behavior shifts.
  * SDK implementation guidance focused on reliability, offline handling, and secure key management.
  * Example requests and responses that reflect real-world payloads.

If something is unclear or missing, please raise an issue through your account team so we can address it quickly.
