5. Zugriffsstatistik (Page-view counting with PostHog)

To see how many people visit, the home page counts page views with PostHog, a service of PostHog Inc., using its EU cloud (eu.i.posthog.com, hosted in the EU). One page-view event is sent per page load: the page address, the referring page, and basic technical data that the PostHog script attaches (browser, operating system, screen size). Clicks, session recordings and surveys are switched off. The PostHog project is set to discard IP addresses.

  • No cookies, no storage: the random visitor id is kept in memory only and forgotten when you leave the page, so every visit is a new anonymous visitor.
  • Do Not Track and Global Privacy Control: if your browser sends either signal, the PostHog script is not loaded at all.
  • You can also block eu.i.posthog.com and eu-assets.i.posthog.com with a content blocker.

Legal basis: Art. 6(1)(f) GDPR, our legitimate interest in knowing how the site is used in aggregate. PostHog processes the data on our behalf under a data processing agreement (Art. 28 GDPR). Details: TELEMETRY.md, "Website".
